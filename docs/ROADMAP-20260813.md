## 0. Today's priority, in one line

**Score the 8,820 live-recorded signals sitting in `quantum.strategy_signals` against forward
returns.** Everything else waits. This single task converts the central question — *does this
signal predict anything?* — from unanswerable-in-decades to answerable today.

**The pipeline generates ~106 candidates per trading day and executes 0.52 of them. The funnel
rejects 99.5% — and every rejection was logged with a price, a timestamp and a reason.**

Two consequences:

1. **Sample.** 8,820 signals is 192× the executed record. At that size the detectable per-trade
   Sharpe is ~0.021 — *smaller than the 0.031 currently observed*. The question is decidable.
2. **Cleanliness.** These were recorded live, in real time, before the outcome existed. That
   makes them genuine out-of-sample predictions — the one thing an LLM-based signal can never
   get from a historical backtest. **This is the single most valuable asset QTP owns, and it
   has never been read.**

## 2. Today — build the signal scorer (P0)

**Question:** does a QTP signal predict the next few days' return, better than chance, after costs?

**Method** (all offline, no trading risk, deterministic and re-runnable):

1. Extract the 8,820 scorable signals: symbol, timestamp, direction, type, confidence, reference price.
2. Pull daily bars for the 556 symbols over the period + a 10-day forward buffer (Alpaca; one
   multi-symbol request per chunk — the minute-bar probe already proved this path works).
3. Forward returns at 1/2/3/5-day horizons from the **next tradable open**, not the reference
   price — the honest entry a real order would get.
4. Sign by direction (LONG +r, SHORT −r).
5. **Subtract the same-day universe mean.** Without this you measure the market, not the signal.
6. **Cluster the standard errors by day.** ~106 signals land the same morning and are heavily
   cross-correlated; naive t-stats on 8,820 rows would be inflated several-fold. This is the
   step that separates an honest result from a flattering one, and I will run it both ways and
   report both.
7. Slice: by signal_type (GAP / NONE / MOMENTUM_SURGE / VIX_COLLAPSE), confidence bucket,
   direction, regime, holding horizon.
8. Then apply QTP's **measured** cost model — 0.30% entry cap, 1.2% stop with 1.67× overshoot,
   TSM tiers — to convert "predicts" into "would have paid."

**Decision rules, precommitted now, before a single number is computed:**

| result | verdict | what happens next |
|---|---|---|
| No slice shows signed excess return > 0 at clustered t > 2 | **KILL** | Shut down with 8,820-sample evidence, not exhaustion. The months of work end with a real answer. |
| Raw signal predicts, post-cost version does not | **COST PIVOT** | The edge exists but is smaller than friction. All work redirects to costs/horizon, none to signal. |
| Only specific slices predict (most likely) | **NARROW** | Trade only that slice; the rest of the funnel is noise. Highest-value outcome. |
| Broad predictive edge survives clustering and costs | **CONTINUE** | Then — and only then — the plumbing and breadth work matter. |

**Second question, same data, same day:** `exec_flow_audit` records which stage killed each
candidate (MTF_CONFLUENCE 913, BROAD_SCANNER_BIAS 929, VC_HARD_KILL 467, BIAS_FILTER 384,
BACKTEST_ENFORCEMENT 274 since June). Score **killed vs passed** at each stage. **A filter that
kills better-than-average candidates is destroying money, and removing it is free alpha.** With
99.5% of candidates being rejected, this is where the largest recoverable value plausibly sits.

## 3. The roadmap

**NOW — today (08-13)**
- **P0 · Signal scorer** — §2. Target: first honest read by end of day. *Nothing competes with this.*
- **P1 · Funnel value test** — killed-vs-passed by stage, same harness, same afternoon.
- Live trading continues untouched under current gates. It costs nothing to leave running, it
  keeps accruing clean forward data, and **its daily P&L is no longer a decision input** — that
  is the discipline change that answers "I can't keep losing money every day." You stop reading
  a number that has t = 0.14.

**NEXT — this week, gated on the verdict**
- If **KILL** → write the shutdown brief with the evidence, wind down deliberately, keep the risk
  framework (it is reusable and genuinely good).
- If **NARROW / COST PIVOT** → rebuild the funnel around what actually predicts; re-run the
  scorer as a regression test on every change. Then breadth: more names, smaller size (§2 of the
  institutional review — same edge at 5 trades/day is a 1.09 Sharpe instead of 0.35).
- If **CONTINUE** → ratchet backtest (the −$1,842 giveback class), then task 68 (`feed=iex`), then M3.

**LATER — only after a verdict**
- Real-money prerequisites unchanged: SIP + NBBO guard (blocked on the Alpaca ticket — **the one
  thing only you can move today**), a live-mode dry run, Conclave sizing.
- The parked backlog (AES clamp-floor, orphan classification, VC C1–C5, G17, the SQL-sweep
  findings) stays parked. None of it changes the answer.

## 4. What we deliberately are NOT doing today

- Not tuning stops, trails, or sizing. Every such change is a guess until §2 reports.
- Not shipping the ratchet — it is a fix for a loss class that only matters if the signal is real.
- Not reacting to today's P&L, whatever it is.
- Not adding features. The system does not need more machinery; it needs one measurement.

## 5. Why this is the right call

You have spent months building risk plumbing that is, honestly, better than most retail systems
and some funds: byte-verified deploys, fail-closed governance, append-only correction trails,
adversarial self-tests. What was never built was the instrument that tells you whether the thing
being protected is worth protecting.

That instrument does not need to be built from scratch. **The measurements have been recorded
faithfully since April — 26,467 of them — by the very logging discipline that felt like
overhead at the time.** Today we read them.

Whatever the answer is, you will have it from 8,820 observations instead of 46, and you will
have it in a day instead of a decade.
