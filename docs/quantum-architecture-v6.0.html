System Architecture v6.0 · Updated August 4, 2026

Quantum Engineering Tradingv6.0

Four-plane trading platform: an Alpha plane that turns scanner signals into sized, protected orders; a Research plane that manufactures evidence off the hot path; a Safety plane that can kill anything at any time; and a Proof plane — the actual moat — that measures whether any of it works. v6.0 is the first revision written against the Conclave-ratified v5.9 shape. Since v5.8 the platform swapped the decision LLM stack (Grok → Claude Opus 4.8 across all four Signal-State-Machine call sites), shipped Gate-K — a real risk manager sized off measured edge — built a second Supabase schema as the measurement spine, fixed a nine-node observability blackout that had been silent since creation, put gate logic under a 17-suite / 181-check regression harness, and deleted surface area: Discovery, Grok-4 vision scoring, Perplexity, Databricks and the screenshot chart-vision path are all retired.

THE OUTCOME, FIRST. v5.8 counted 40+ nodes, 14 defense layers and 3 AI models as achievements. Phase 0 then proved the deployed confluence score was anti-predictive and the bracket geometry was a coin flip — the platform's losses came from unmeasured machinery believed to be working, never from missing machinery. v6.0 is what that verdict looks like once executed: node count is down, measured surface is up. Every gate now carries a Filter/Guard classification and an expiry; every live decision module has a pure spec-mirror in lib/ pinned by a Maya regression suite; every order is sized by a Postgres function reading measured R out of public.trade_ledger, not by a backtest. The honest headline for August: the machinery is now instrumented and the sizing is now disciplined — but live edge is still in probation (n<40 closed trades/strategy, t-stat has not cleared 2), so nothing here yet claims a proven edge. That is the point. The moat is the evidence loop, not the node count.

FILTER/GUARD DOCTRINE
v5.8 advertised "14 defense layers" as a feature.
