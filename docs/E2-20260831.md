# E2 — Entry-Edge Null Test: QTP's candidates carry no measurable alpha (2026-08-31)

**Question (PO-authorized this morning):** do the entries themselves have edge, or has
six months of work been tuning the exit of trades whose entry is noise?

**Answer: no measurable edge.** Across 904 deduplicated long candidate-days over 90
days, QTP's picks are statistically indistinguishable from random draws on the same
universe — and the deep-filtered survivors point-estimate *worse* than random.

## Method (engine-parity, fully reproducible)

- **Candidates:** every long-side audit row (side BUY/LONG) 06-02→08-20, deduped to
  first per symbol-day, requiring full bar coverage: **n=904** (T0). Tier T2 = deep
  survivors — passed VC, bias, MTF, AI, backtest, regime; killed only by Gate-K or
  executed: **n=144**. Tables: `quantum.e2_candidates_20260831`, `e2_outcomes_20260831`.
- **Policy simulated:** the ratified cell — entry at d0 close, 2.5% stop (gap-at-open
  fills at open, stop-first intraday), exit at close of d0+2. Sim runs in SQL;
  **parity-proven against the real E1 engine (`lib/analysis/exit_grid.js`): 25/25
  identical R values.** Same sim, same window, same rules for every series — sim
  biases cancel in the comparisons.
- **Nulls, 1:1 matched per candidate, deterministic seeds:** N1 random symbol same
  day; N2 same symbol random day; N3 SPY same day (n=609, SPY bar coverage).
- **Inference:** paired day-block bootstrap (10,000 resamples; the unit is the DAY,
  because candidates cluster — 100 of 144 T2 candidates land on 08-18→20).

## What this means, plainly

1. **The entry funnel selects nothing.** Raw candidates perform like darts thrown at
   the same watchlist on the same days — slightly worse, in fact, against every null.
2. **Six gates of filtering add ~nothing and may anti-select.** T0→T2 improves mean R
   by +0.009 while random selection from the same days offered +0.19 to +0.28. The
   deep survivors underperform random symbol draws with p(Δ≤0)=0.94 — the filter
   stack is, at best, expensive noise on this sample.
3. **The tape, not the picks, produced every positive number.** All series are mildly
   positive (drift); the live book still lost because fills, fees, and the dead exit
   half ate a thin drift the picks never beat.
4. **Therefore: no exit policy, stop width, filter, or model swap can make this
   signal source profitable.** That question is now closed with n=904, which
   outweighs anything the live n=20 cohort could add — the cohort tests the same
   entries at higher cost per datapoint.

## Caveats, honestly stated

Daily-bar sim with entry at d0 close (QTP enters intraday; identical assumption
across all series and in E1); one 90-day, chop-up regime; T2 alone is small and
surge-clustered (n=44 pre-surge) — the T0 result carries the conclusion; fees and
slippage excluded symmetrically. None of these plausibly manufactures a null result
out of real edge at this sample size.

## The reusable asset — and the E2-branch options (pre-agreed this morning)

Six months did build something valuable: a **signal-evaluation pipeline** — audit
trail of every candidate, an engine-parity simulator, null baselines, and honest
inference — that can score ANY candidate generator against the same bars in an
afternoon, before a dollar is risked. The options it now serves:

- **A. New signal source, same harness.** Design candidate generators (momentum
  continuation, gap-and-go, mean-reversion screens, universe/timeframe variants) and
  E2-score each against nulls. Only a generator that beats its nulls graduates to
  paper. Cost: analysis sessions, zero live risk.
- **B. Human-in-the-loop product.** The one green bucket in 90 days is manual exits
  (+$1,784, 6/12). Reposition QTP as surfacing + sizing + protection + audit, with
  the PO pulling the trigger. The infrastructure is already exactly this good.
- **C. Stop.** Also honest. The measurement machine is the deliverable.
