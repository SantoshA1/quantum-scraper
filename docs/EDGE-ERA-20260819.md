"trading is broken" months of governance ago; we now find "the spare tire is flat."

expectancy leaks. This is a testable claim, not a story.

## 5 · The plan — one experiment, then a loop

**E1 — the exit-policy grid (next build; shadow; zero risk; no PO action).**
Re-score BOTH cohorts — the ~100 executed certified trades and the ~330 blocked BUYs —
under a grid of exit policies, using the bars + walk-forward stop machinery the RCF scorer
already runs nightly: stop ∈ {live 1%, 1.5×ATR, 2.5%, p99-gap-aware} × exit ∈ {2-day
time, 5-day time, 2R target, trail}. Output: a PF/expectancy table per cell, per cohort.
**Pre-committed decision rule: a cell must clear PF > 1.2 on both cohorts independently
before it goes to Conclave as a proposed exit-policy change at probation size.** If no
cell clears, the entry engine is the problem and we know to stop polishing exits. Either
result is progress; neither risks a dollar.

**E2 — Gate-K blocked-BUY shadow scoring** (already authorized): folds into E1 as the
third cohort — every `negative_measured_edge` block gets the same grid. "Are we missing
good trades" becomes a permanent table.

**E3 — regime-conditional arms (after E1 reads out):** the tape is CHOP/VIX-24 and the
scanner is a momentum engine; LYB today was a 28-RSI oversold name being bought on a gap.
If E1 shows entries are salvageable, the next grid axis is regime-conditioned entry
(momentum in TREND, fade in CHOP) — same shadow harness, same rule: measure first.

**Not the plan:** loosening any gate on hope. The two-week no-touch stands. The gates are
the only reason this month's tuition was paper-priced.
