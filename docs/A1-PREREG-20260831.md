# A′-1 pre-registration — overnight vs intraday decomposition (2026-08-31, BEFORE ANY RUN)

First A′ test under the gov-246 charter. Frozen before results; a MAP question
first (where does the drift live), gating any overnight-family construction.

## Constructions (frozen)

Window: the E4 window (221 trading days, 2025-10 → 2026-08-28) on
`quantum.scorer_bars_daily`, equal-weight across all symbols with valid values
each day. Three return slices per day d:
- **ON (overnight)**: o_d / c_{d−1} − 1
- **ID (intraday)**: c_d / o_d − 1
- **FULL (close-to-close)**: c_d / c_{d−1} − 1 (identity check: ON ⊕ ID ≈ FULL)
Same three slices for SPY alone (separates a universe effect from a market-wide
one). Metrics per series: compounded total, annualized, Sharpe, max drawdown.

## Inference and graduation (frozen)

Primary comparison: universe ON − ID daily difference, paired day-block
bootstrap, 2,000 resamples (salt `a1boot`), p(Δ≤0) ≤ 0.05 (single primary test;
SPY is reference, not gated).

**Economic bar, stated honestly:** harvesting overnight-only means a full daily
round trip — at the standing 5 bps/side that is ~10 bps/DAY (~25%/yr) of cost.
Graduation to any tradeable proposal therefore requires ON *net of 10 bps/day*
≥ FULL buy-and-hold. Literature says the statistical split is likely real and
the net-of-cost bar is likely fatal at retail costs — if so, the honest verdict
is "mapped, not tradeable," which still gates smarter constructions (e.g.,
overnight exposure via holding periods rather than daily churn) for a future
pre-registered round.

## Limitations

IEX opens for thin names can be noisy; survivorship caveat on the universe as
declared in E4; single ~11-month window; costs modeled flat.
