# E3 round 3 pre-registration — the hold-horizon axis (2026-08-31, BEFORE ANY SIMULATION)

Committed before results exist; nothing here changes after they do.

## Question

Rounds 1–2 established: momentum-symbol drift is the only recurring positive, and
no entry-timing rule beats random timing at a 2-day horizon. Round 3 asks whether
that drift COMPOUNDS: do longer holds on the same signals clear an economic bar
that 2-day scratches structurally cannot?

## What is fixed and what varies

- **Signal set FIXED:** the round-2 G5 spec VERBATIM (leader deep pullback:
  c ≥ 1.10×c₍d−20₎, c ≤ 0.97×max(h over d−5..d−1), c ≥ 0.90×h20; 5/day cap by
  momentum; dedup per sym-day), regenerated over signals d0 ∈ [2025-10-06,
  2026-08-14] so 10-day exits complete within bar coverage (…08-28).
- **What varies — 4 primary cells:**
  A1 = 5-day hold, 5% stop · A2 = 5-day hold, no stop ·
  A3 = 10-day hold, 8% stop · A4 = 10-day hold, no stop.
  Same daily-walk sim rules (entry d0 close; gap-at-open through stop → open;
  stop-first intraday; day-H close otherwise; no-stop cells exit at day-H close).
- **Metric:** RAW RETURN % on entry (R-multiples are not comparable across stop
  widths). PF computed on return %.
- **Nulls:** N1 rand-sym same day, N2 same-sym random day, matched 1:1, simulated
  under the SAME cell rules; md5 seeds salted per cell. Paired day-block bootstrap,
  1,000 resamples per cell (salt `e3r3boot`).

## Declared contamination and its mitigation

G5 was selected as round 2's best of three specs, and this window contains round
2's segment. The HORIZON dimension is new, but spec-selection bias exists.
Mitigations, frozen now: (1) Bonferroni across the 4 cells (p ≤ 0.0125 per null);
(2) results are reported for the FULL window AND separately for the **fresh
segment** (signals 2026-04-14 → 2026-08-14, never used for spec selection); a cell
only graduates if the fresh-segment point estimate is also positive vs both nulls;
(3) no parameter adjustments after results, ever.

## Graduation rule (frozen)

A cell graduates to a Conclave paper proposal ONLY if ALL hold:
1. mean return > both nulls (point estimates), full window;
2. bootstrap p(Δ≤0) ≤ 0.0125 vs EACH null, full window;
3. economic bar: mean return ≥ +0.30% (5d cells) / ≥ +0.50% (10d cells) —
   fees/slippage haircut plus capital-time cost;
4. n ≥ 60; 5. fresh-segment point estimates positive vs both nulls.

## Limitations

Daily bars; IEX feed; one ~11-month span; overlapping holds measure selection not
portfolio construction; longer horizons mean fewer independent day-blocks per
signal (the day-block bootstrap remains the inference unit).
